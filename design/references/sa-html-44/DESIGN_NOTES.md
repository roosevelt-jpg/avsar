# S&A Recruitment 3.0 — S&A corporate design review

This is an original corporate recruitment UI direction informed by established international recruitment standards. The design and branding are specific to S&A Recruitment.

## Scope
44 interconnected HTML entry points across public, candidate, employer, admin and CMS.

## Launch
Open `index.html` or serve this directory with `python -m http.server 8080`.

## Demo limitations
This is a browser-local prototype. It is not a production backend. Example jobs, profiles, employers and metrics are fictional and must be replaced with verified live data. Role selection is not secure authentication. Do not enter real personal information.

## Assets
The local image crops in `assets/images` come from the generated S&A concept artwork, created for the prototype. CSS and JavaScript are shared by all 44 pages.
