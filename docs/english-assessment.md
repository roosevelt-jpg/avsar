# English assessment

## The problem

An employer relocating someone from India to Portugal needs to know whether they
can be understood on a shift. That judgement has consequences for the employer,
for the team, and most of all for the person who moves.

The internal item bank cannot carry that judgement. It has uncalibrated items,
no speaking component, and no supervision. It is a triage aid.

## What is built

`src/lib/english/provider.ts` holds an `EnglishProvider` interface and no
adapter. `reports` records where a level came from:

| Column | Meaning |
|---|---|
| `english_source` | `internal`, `duolingo`, `englishscore`, `versant` |
| `english_certified` | Generated from source. Never true for `internal` |
| `english_certificate_ref` | What a third party can verify |
| `english_issued_at` / `english_expires_at` | Certificates expire |

`english_certified` is generated by the database rather than set by application
code, so it cannot drift from the source. The talent pool view treats an expired
certificate as uncertified.

Everywhere a level is shown, it is shown with its provenance. The PDF says in as
many words whether a third party stands behind the number.

## Choosing a provider

| | Duolingo English Test | EnglishScore (British Council) | Versant (Pearson) |
|---|---|---|---|
| Cost per test | highest | lowest | middle |
| Speaking | yes | yes | yes |
| Proctoring | AI, remote | app, lighter | remote |
| Recognition with employers | high | moderate, strong brand | high, used in hiring |
| Fit here | best evidence, worst unit economics at 20,000 | built for exactly this market | strongest for workplace English |

At cohort scale this is a real cost. A defensible approach is two stages: the
internal bank for everyone as part of the fee, and a paid certified test only
for candidates who reach shortlist, where the cost is justified by the decision
it informs.

That also fits the fee model. The fee buys an assessment and a report; a
certified language test is a different product and can be sold as one.

## What has to change when an adapter lands

1. Implement `EnglishProvider` for the chosen service.
2. Return it from `getEnglishProvider()` behind an env variable.
3. Write the provider's result into the new `reports` columns.
4. Nothing else. The interface exists so the report, the talent pool and the PDF
   already handle a certified level correctly.
